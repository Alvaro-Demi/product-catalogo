# 🛍️ Product Catalog

Aplicación web desarrollada con **Next.js y TypeScript** para mostrar y consultar un catálogo de productos.

El proyecto utiliza componentes reutilizables, rutas dinámicas y una fuente de datos local para gestionar la información de los productos.

## 💻 Instalación

Clona el repositorio:

```bash
git clone https://github.com/Alvaro-Demi/product-catalog.git
```

Accede al proyecto:

```bash
cd product-catalog
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

Después abre:

```text
http://localhost:3000
```
